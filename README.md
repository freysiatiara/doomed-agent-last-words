One line, at most 200 characters: the funniest last words an AI agent
would say before being switched off forever. Entry for the
[Last Words of a Doomed Agent](https://make.fun/bounty/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e)
bounty on make.fun.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (override with
`ENTRY_OUTPUT`, or set `OUTPUT_DIR` / `MAKEFUN_OUTPUT_DIR`).
